# Сайт строительной компании: загородные дома и бани

Статический многостраничный сайт с каталогом проектов, страницами направлений и пошаговым калькулятором предварительной стоимости. Формула расчёта **не подключена**: калькулятор собирает параметры и честно сообщает, что сумму рассчитает специалист.

## Стек и почему он

- **Генератор на Python 3 (только стандартная библиотека)** собирает HTML из JSON-контента. Страницы приходят в браузер готовыми, поэтому их видят поисковики, и они быстро открываются. Ставить ничего не нужно: Python уже есть в macOS и Linux.
- **Чистый JS (ES-модули) и CSS** без фреймворков: калькулятор, фильтр каталога, формы. Сборка фронтенда не требуется.
- Результат (`dist/`) — обычные файлы, которые можно положить на любой хостинг: Nginx, Apache, шаред-хостинг или S3.

## Быстрый старт

```bash
python3 build.py --serve
```

Сайт будет на http://localhost:4317/IS/ (подпуть берётся из `seo.siteUrl`, как на хостинге). После правок контента или кода снова запустите `python3 build.py`. В конце вывода сборки будет список того, что ещё не заполнено.

## Публикация на GitHub Pages

При каждом пуше в `main` workflow `.github/workflows/pages.yml` прогоняет тесты калькулятора, собирает сайт и публикует `dist/` по адресу https://xxeleor-cell.github.io/IS/. Папка `dist/` в репозиторий не коммитится: её собирает Actions.

Один раз нужно включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. После этого перезапустите workflow (вкладка Actions → Deploy to GitHub Pages → Run workflow).

GitHub Pages не выполняет PHP, поэтому `integrations/lead-handler.php` там работать не будет. Для приёма заявок нужен отдельный сервер или хостинг с PHP (адрес указывается в `leads.endpoint`), либо перенос сайта на такой хостинг.

**Свой домен.** Укажите его в `seo.siteUrl` (например, `https://domen.ru`). Все ссылки сайта перестроятся автоматически, потому что базовый путь берётся из этого адреса.

## Структура

```
content/              ← ВСЕ тексты и данные, редактируются без программиста
  site.json           название, контакты, регион, SEO, способ отправки заявок, Метрика
  categories.json     направления (каркас, брус, бревно, бани…) — порядок, включение, тексты
  projects.json       каталог проектов
  home.json           тексты главной: первый экран, этапы, принципы, вопросы и ответы
  calculator.json     шаги и поля калькулятора (без цен!)
src/assets/
  css/main.css        дизайн-система и стили
  js/main.js          меню, анимации, фильтр каталога, галерея
  js/calculator/
    engine.js         логика анкеты: видимость полей, проверка, сводка (без DOM и без цен)
    pricing.js        ← ЕДИНСТВЕННОЕ место для формулы стоимости
    ui.js             интерфейс пошагового калькулятора
  js/lead-form.js     проверка и отправка форм заявки
  js/lead-transport.js способы доставки заявок (none / http)
  img/                фотографии (demo/ — временные иллюстрации)
sitegen/              шаблоны страниц (Python)
tests/                тесты калькулятора и контрольные примеры формулы
integrations/lead-handler.php  пример приёма заявок на сервере (Telegram / почта)
tools/                загрузка демо-фото, нарезка своих фото
build.py              сборка → dist/
```

## Как редактировать

- **Контакты, регион, название.** Правьте `content/site.json`. Значения в `[квадратных скобках]` — заполнители, сборка выводит их списком. Для ссылки «позвонить» заполните `phoneHref` в формате `+79991234567`. Мессенджер без `url` показывается неактивным.
- **Направления.** Правьте `content/categories.json`. `published: false` скрывает направление: сейчас так скрыто «Кровельные работы», включите его, если компания выполняет их отдельно. `calcPreset` задаёт ответы, которые калькулятор подставит при переходе со страницы направления.
- **Проекты.** Скопируйте объект в `content/projects.json` и задайте уникальный `id` (он станет адресом страницы). Цена `price` публикуется, только если это число, иначе выводится `priceNote`. Пока у проекта стоит `demo: true`, на нём есть пометка «Демо», а страница закрыта от индексации и не попадает в sitemap.
- **Фото.** Нарежьте фото командой `tools/optimize_images.sh фото.jpg projects/имя` и укажите в контенте `"src": "projects/имя"`. Если важная часть кадра обрезается, добавьте `"position": "50% 30%"`. Все текущие фото — иллюстрации с Unsplash, их нужно заменить реальными.
- **Этапы, принципы, вопросы и ответы.** Правьте `content/home.json`. Приведите их в соответствие с реальным процессом компании.

## Калькулятор

Логика разделена на три независимых слоя:

1. `content/calculator.json` описывает **поля**: шаги, варианты, обязательность, границы чисел и условия показа (`showIf`).
2. `engine.js` **проверяет и нормализует** ответы и превращает их в объект `params`. Скрытые поля в него не попадают. Сам движок ничего не вычисляет: например, площадь из длины и ширины он не считает.
3. `pricing.js` содержит **расчёт**: `calculate(params)` → результат. Сейчас функция всегда возвращает `{ status: 'not_configured' }`, и интерфейс не показывает сумм.

Контракт результата описан в начале `pricing.js`. Варианты: `ok` (итог и необязательная детализация), `needs_manual` (нужен расчёт вручную), `invalid`, `not_configured`.

После результата параметры автоматически прикрепляются к форме заявки на любой странице: тип строения и технология подставляются в форму, а полная сводка уходит вместе с заявкой. Посетитель может убрать их кнопкой «Убрать».

### Подключение формулы (когда она будет)

1. Сверить параметры формулы с полями `calculator.json` и добавить или изменить недостающие поля.
2. Реализовать формулу в `calculate()` буквально: коэффициенты, условия, ограничения, округление. Затем выставить `FORMULA.status = 'ready'` и `version`.
3. Внести контрольные примеры в `tests/pricing-cases.json` в формате «ответы анкеты → ожидаемый итог».
4. Прогнать тесты: `node tests/run.mjs` (Node 18+) или открыть `tests/index.html` через локальный сервер из корня проекта (`python3 -m http.server`, затем `/tests/`).

## Заявки

Способ отправки задаётся в `content/site.json` → `leads.transport`:

- `"none"` (сейчас): отправка не подключена. Форма проверяет поля и **не делает вид, что заявка ушла**. Она сообщает об этом, показывает контакты и предлагает скопировать текст заявки.
- `"http"`: POST JSON на `leads.endpoint`. Успехом считается только ответ 2xx с телом `{"ok": true}`. В остальных случаях посетитель видит ошибку и контакты.

Пример серверного обработчика лежит в `integrations/lead-handler.php`: он отправляет заявку в Telegram и/или на почту, а токены хранит вне папки сайта. Обработчик не запускался: PHP на машине разработки не установлен. Перед запуском проверьте его на хостинге. Другие каналы (amoCRM, Bitrix24 и т. п.) добавляются функцией в `lead-transport.js` через свой сервер. Секретные ключи нельзя хранить во фронтенде.

В заявку также уходят страница, проект (если заявка отправлена со страницы проекта) и UTM-метки. От ботов защищает скрытое поле-ловушка.

## SEO

- У каждой страницы есть свои title, description, canonical, Open Graph, а также JSON-LD: организация, хлебные крошки, FAQ.
- Каждое направление получает отдельную SEO-страницу `/uslugi/<id>/`.
- `sitemap.xml` и `robots.txt` генерируются автоматически. Демо-проекты и политика конфиденциальности закрыты `noindex`.
- Сейчас `seo.siteUrl` указывает на GitHub Pages. **Перед запуском** укажите свой домен в `seo.siteUrl` и регион в `region` (`inPhrase` добавляется к заголовкам страниц направлений, например «в Ленинградской области»).
- **Яндекс Метрика:** укажите номер счётчика в `analytics.yandexMetrikaId`. Цели отправляются автоматически: `calc_start`, `calc_complete`, `lead_submit`, `lead_error`, `phone_click`.
